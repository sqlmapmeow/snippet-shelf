Your data, explained.

Snippets are stored in this browser’s localStorage for this website. They are not uploaded or synced to GitHub.

This is not encrypted storage. Other scripts on the same origin and people using your browser profile may access it. Do not store secrets.

Clearing site data or using a different browser or address can make your shelf unavailable. Export a JSON backup before switching devices.

If storage is blocked, the app uses a clearly marked session-only mode. No data survives closing that session.
